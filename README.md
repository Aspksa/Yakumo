# Yakumo

Ядро приложения на Python (только стандартная библиотека, Python 3.10+).

## Запуск

- Windows: двойной щелчок по `Yakumo.bat` (или `Yakumo.bat --info`).
- Любая ОС: `python -m yakumo`.

`Yakumo.bat` ищет Python по порядку: `python\python.exe` рядом с программой,
`.venv`, `py -3`, `python` из PATH, стандартные папки установки. Если рабочего
Python нет, предлагает скачать встроенный Python (около 10 МБ с python.org) в
папку `python\` рядом с программой, без установки в систему
(`launcher\get_python.ps1`). `Yakumo.bat --hidden` запускает без окна
консоли (управление через значок в трее).

Запускается только один экземпляр: повторный запуск не поднимает второй сервер,
а открывает в браузере уже работающий.

## Настройки в веб-версии

Значок шестерёнки слева. Изменения сохраняются сразу в `config/yakumo.json`:
открывать браузер при старте, значок в трее (нужен перезапуск), запуск вместе
с Windows (запись в `HKCU\...\Run`, без консоли и браузера, через `Yakumo.pyw`),
язык RU/EN и компактный режим. В разделе «Оформление»: акцентный цвет (21
вариант, среди них мёд #d9a441, золото, янтарь, сакура, лазурь, нефрит,
серебро), масштаб текста и элементов всего приложения (80–150%), скругление
углов карточек и кнопок, прозрачность карточек и режим экономии (анимации стоят,
пока окно Yakumo не активно).

## Аватар и чат

На всех страницах веб-версии есть аватар Yakumo (кицунэ). Его можно перетащить
мышью или пальцем в любое место экрана, позиция запоминается в браузере. По
нажатию открывается окно чата рядом с аватаром.
В настройках, в разделе «Аватар», можно выбрать образ (классика, объятия,
нежность, молитва, смущение, приглашение, поклон, почтение, сон), скрыть аватар,
изменить размер ползунком
(120–2000 точек, но не больше окна), выбрать движение (нет, парение, мягкое
парение, «живая»: дышит, покачивается, моргает, поворачивается к курсору и
подпрыгивает от нажатия), сияние, скорость анимации, закрепить аватар на месте,
показывать эффекты всегда или только при наведении, и сами эффекты, несколько сразу:
золотые искры, кицунэ-би, лепестки сакуры, золотая пыльца, светлячки, листья
гинкго, золотая аура, бабочки, золотой туман, падающие звёзды и иероглифы. Картинка
остаётся целой; для моргания поверх кладётся маленький кусок с закрытыми
глазами (`tools/avatar_blink.py`, пока только у классического образа). Картинки
образов увеличены нейросетью до 2508 точек, края почищены; уменьшенные копии
для разных размеров делает `tools/avatar_images.py`.

Чат работает через [Cloud.ru Foundation Models](https://cloud.ru/docs/foundation-models/ug/topics/quickstart).
В настройках, в разделе «Cloud.ru»: вставить API-ключ и нажать «Сохранить»
(связь проверится сразу), затем выбрать модель. Ключ хранится отдельно от
настроек, в `config/secrets.json`, и в браузер целиком не передаётся. Ответ
приходит по мере набора, его можно остановить; переписка хранится в браузере,
кнопка с корзиной в шапке чата её очищает.
Окно чата (по умолчанию 420×600) меняет размер, если потянуть мышью за край или
угол; размер запоминается. Кнопка в шапке разворачивает чат на всё окно. У
сообщений есть время и кнопка «Копировать», после ошибки можно повторить запрос,
в пустом чате показаны подсказки. Enter отправляет, Shift+Enter переносит строку,
Esc закрывает чат.

## Доступ из локальной сети

На компьютере, где запущена Yakumo, приложение открывается без пароля. С других
устройств все страницы, файлы и команды API требуют входа. До задания пароля
сетевой вход закрыт, в том числе при запуске с `--lan` или явным `--host`.

1. На основном компьютере откройте «Настройки → Доступ по сети».
2. Сохраните пароль длиной от 8 до 128 символов.
3. Запустите с `Yakumo.bat --lan` и откройте LAN-адрес Yakumo на другом устройстве.
4. Введите заданный пароль на странице входа.

Пароль можно изменить или удалить только с основного компьютера. «Закрыть
сетевой вход» завершает сетевые сеансы и закрывает новые входы; смена пароля
тоже завершает старые сеансы. Сеанс действует 12 часов и завершается при
перезапуске Yakumo. Повторные неверные попытки входа ограничены.

В `config/access.json` хранится соль и хеш PBKDF2-SHA256; сам пароль не
сохраняется. Сеансы используют cookie HttpOnly и SameSite=Strict. Подключение
пока идёт по HTTP: эта защита предназначена для доверенной локальной сети,
не для прямого открытия порта в интернете или работы через обратный прокси.

Исключение — ссылки «Поделиться»: их секретный токен открывает выбранный файл
или папку без входа. Список остальных файлов и команды изменения требуют
авторизации. Отозвать ссылку можно на странице «Диск».

## Значок в трее

Нужны `pystray` и `Pillow`: `pip install -r requirements.txt` (в портативной
сборке уже есть). Меню: «Открыть», «Папка данных», «Рабочая папка», «Модули»,
«Выход». Без этих библиотек Yakumo работает в консоли, как раньше.
Отключить: `--no-tray` или `"tray": false` в настройках.

## Портативная сборка

```
python tools/build_portable.py
```

Скачивает встроенный Python для Windows (по умолчанию 3.12.10), кладёт его в
`python\`, ставит библиотеки для трея, добавляет маркер `portable` и собирает
`dist/Yakumo-portable-win64.zip`. Архив можно распаковать на флешку и запускать
`Yakumo.bat` без установки Python; данные хранятся рядом в `YakumoData`.

## Диск

Значок облака в верхнем меню — личное хранилище файлов, как Яндекс Диск или
Облако Mail.ru, только файлы лежат у вас: на том же диске, что и программа.
Если Yakumo стоит на переносном диске, «Диск» переезжает вместе с ним, а смена
буквы диска (`E:` → `F:`) ничего не ломает — все пути внутри относительные.

- Папки и файлы плиткой (с миниатюрами картинок) или списком, сортировка по
  имени, дате, размеру и типу, поиск по всему Диску.
- Загрузка кнопкой или перетаскиванием файлов и целых папок с компьютера;
  перетаскивание внутри Диска переносит в папку. Одинаковое имя не затирает
  старый файл, а даёт `имя (2).txt`.
- Просмотр картинок (листание стрелками), видео и музыки с перемоткой, PDF и
  текстов (UTF-8 и windows-1251); остальное скачивается. Папка скачивается
  zip-архивом.
- Переименование (F2), перемещение, копирование, удаление в корзину (Delete) с
  восстановлением, очистка корзины.
- «Поделиться» даёт ссылку на файл или папку. С телефона и других устройств
  она открывается, если Yakumo запущен с доступом из сети: `Yakumo.bat --lan`.
- Внизу шкалы — сколько занято Диском и сколько свободно на носителе.

Умный поиск (значок ✦ рядом с поиском):

- Поиск идёт не только по именам, но и по тексту внутри документов: txt (UTF-8
  и windows-1251), Word, Excel, PowerPoint, OpenDocument, PDF, RTF, FB2, EPUB.
  Окончания слов не мешают: «квитанции» находит «квитанция». Текст читается в
  фоне и хранится в `.yakumo/index.db`. PDF читает встроенный разборщик; если
  установлен `pypdf`, используется он.
- По желанию — распознавание фото через Cloud.ru: модель, которая видит
  картинки (берётся из каталога сама), описывает каждое фото, и по описаниям
  работает поиск («чек», «кошка», «море»). Выключено, пока вы не включите: без
  этого фото никуда не отправляются. С Pillow фото перед отправкой уменьшаются.

Yakumo в чате умеет работать с Диском: «найди договор аренды», «перескажи
отчёт.pdf», «сколько места осталось», «разложи Загрузки по папкам». Искать и
читать она может сама, а изменения (папки, перенос, переименование, корзина)
только предлагает списком — они выполняются по кнопке «Выполнить». Ссылки на
файлы в её ответах открывают их на Диске.

Где лежат файлы: в портативном режиме `YakumoData\disk`, иначе папка
`YakumoDisk` рядом с программой (путь показан на странице Диска). Корзина и
ссылки хранятся там же в служебной папке `.yakumo`.

## Память

Значок мозга в верхнем меню — долговременная память Yakumo. Она помнит вас,
ваших близких и ваши дела и видит это в каждом новом чате.

- **Сама учится.** После паузы в разговоре (около 20 секунд) Yakumo выписывает
  факты, людей, питомцев, места и проекты, обещания, даты и конспект беседы.
  Для этого текст разговора ещё раз уходит в Cloud.ru. Пароли, ключи и номера
  документов она записывать не должна.
- **Граф жизни и карта.** Факты связаны с людьми и местами («Катя — сестра,
  живёт в Казани»). На вкладке «Карта» вы в центре, а вокруг золотые узлы.
- **Источник каждого факта.** «Откуда ты это знаешь?» — цитата и разговор.
- **Обещания и даты.** «Сдам отчёт в пятницу», «напомни позвонить маме»,
  дни рождения. Сроки видны в подсказке и на вкладке «Обещания и даты».
- **Сон кицунэ.** Раз в сутки (после 4 утра, когда в чате тихо 20 минут)
  Yakumo склеивает повторы и пишет первой: что ей «приснилось», о чём не
  забыть, как успехи с целью, «а помнишь, год назад…». На аватаре загорается
  золотая точка. Кнопка «Уснуть сейчас» запускает сон вручную.
- **Поиск по смыслу.** Если в каталоге Cloud.ru есть модель эмбеддингов
  (например, bge-m3), «машина» находит факт про «автомобиль». Векторы лежат в
  `brain/vectors.json`.
- **Навыки.** «Запомни, как я делаю недельный отчёт» — шаги сохраняются, а
  «сделай недельный отчёт» Yakumo выполняет по ним.
- **О себе.** Как вы её называете, общие шутки — её характер растёт с вами.
- **Настроение** (выключено по умолчанию): после нескольких тяжёлых дней
  Yakumo говорит бережнее.
- **Что открыто на компьютере** (только Windows, выключено по умолчанию):
  раз в минуту — активная программа. Заголовки окон не сохраняются, только
  минуты по программам за день.
- В чате: «запомни…», «забудь…» (по кнопке), «помнишь, мы говорили про…».
- Частые факты крепнут, мелочи тускнеют и через полгода забываются.
  Закреплённые (★) и добавленные вами не забываются.

Память лежит в `<данные>/brain/` и переезжает вместе с носителем. Экспорт и
импорт — одним файлом на странице «Память».

### Саморазвитие 24/7

Сама модель не переобучается, зато всё вокруг неё растёт, пока Yakumo запущена.

- **Разум и режимы.** Yakumo бодрствует, пока вы пишете. Через 5 минут тишины
  она дремлет: разбирает Диск и считает векторы. Через час (ночью через
  10 минут) засыпает: спит, учится, сдаёт экзамен. На аватаре в это время
  видны «z». Вкладка «Разум» показывает режим и очередь мыслей.
- **Бюджет.** Фоновые запросы к Cloud.ru ограничены за сутки: 50, 150, 300
  (по умолчанию), 1000 или без ограничения. Чат и разбор разговоров в
  бюджет не входят.
- **Думает перед ответом.** Рассуждения в `<think>…</think>` не показываются,
  в чате видно только «Думаю…». Расчёты Yakumo делает инструментом `calc`.
  Если она не уверена, она так и пишет.
- **Длинные задачи в фоне.** Например: «разбери все договоры и составь таблицу
  сроков». Yakumo работает только читающими инструментами. Результат придёт
  сообщением в чат, задачу можно отменить.
- **База знаний по Диску.** Документы режутся на фрагменты и ищутся по смыслу.
  Ответ Yakumo даёт со ссылкой на файл (`knowledge_search`). Хранится в
  `brain/knowledge.json`. Во сне Yakumo пишет конспекты по вашим проектам.
- **Уроки.** Ночью Yakumo строго проверяет свои ответы, а днём замечает ваши
  поправки. Из этого получаются правила, которые она видит в каждом разговоре.
- **Стиль.** Раз в неделю Yakumo переписывает свою инструкцию «как отвечать».
  Все версии хранятся, любую можно вернуть.
- **Желания.** Если Yakumo чего-то не смогла, она это запоминает.
- **Навыки из повторов.** Если одна цепочка инструментов встретилась трижды,
  Yakumo предложит сохранить её как навык.
- **Свои инструменты.** Через `tool_propose` Yakumo пишет функцию на Python.
  Разрешены только math, datetime, re, json и подобные модули; файлов, сети и
  программ нет. Функция запускается в отдельном процессе не дольше 5 секунд и
  включается только после вашего согласия на вкладке «Рост».
- **Ассоциации и архив.** Во сне Yakumo находит связи между фактами: на карте
  они показаны пунктиром, а одну она может упомянуть утром. Потускневшие факты
  уходят в архив: в подсказку они не попадают, но поиском находятся.

- **Сильное мышление.** Сложную задачу (`deep_think`) решают три «внутренних
  голоса»: аналитик, скептик и практик. Потом «критик» сравнивает их решения,
  ловит ошибки и собирает лучший ответ.
- **👍/👎 в чате.** Ответ с 👍 становится образцом для стиля. После 👎 Yakumo
  разбирает, что было не так, и выводит урок. В ответ на 👎 можно объяснить,
  что не понравилось.
- **Любопытство.** Раз в день Yakumo находит пробел в памяти и задаёт вам один
  вопрос.
- **Укрепление уроков.** Во сне повторы склеиваются, а частные случаи
  обобщаются.
- **Рост мозга.** На вкладке «Разум» видно, сколько «нейронов» (всего, что
  Yakumo знает) и связей между ними, и как это меняется по дням.
- **Наперёд.** Раз в день Yakumo смотрит на сроки, обещания, привычки этого дня
  недели и недавние разговоры. Что понадобится, она готовит заранее в фоне,
  о мелочах просто напоминает.
- **Учёба на правках.** Yakumo может создать на Диске файл .md или .txt
  (`disk_write`, по кнопке). Если вы потом его поправите, она сравнит версии и
  поймёт, как писать иначе.

Всё это выключается одним переключателем «Саморазвитие во сне».

## Обновление проекта из GitHub

Раздел «Обновление проекта» добавляет встроенный модуль `modules/update`.
Источник закреплён за `Aspksa/Yakumo`; установка доступна на компьютере, где
запущена Yakumo. Вход по паролю с другого устройства не даёт права менять
код программы или токен обновления.

1. Нажмите «Проверить обновления». По умолчанию используется ветка `main`.
   Можно выбрать последний опубликованный выпуск; если выпусков ещё нет,
   GitHub вернёт понятную ошибку, и можно вернуться к `main`.
2. Нажмите «Скачать и проверить». Загружается архив конкретного коммита,
   проверяются имена, размеры, Git blob-хеши всех файлов и синтаксис Python.
   До этого момента работающие файлы программы не меняются.
3. Нажмите «Установить и перезапустить». Yakumo завершится; отдельный
   установщик сохранит заменяемые файлы, установит подготовленную версию
   и проверит запуск сервера и модулей. При ошибке он восстановит копию
   и запустит предыдущий код. Страница подключается после перезапуска.
4. Кнопка «Вернуть предыдущую версию» восстанавливает последнюю резервную
   копию. Перед откатом также сохраняется текущее состояние файлов.

В настройках модуля можно включить автопроверку раз в час или раз в день.
По умолчанию она выключена. Автопроверка сообщает о версии; установка
выполняется только кнопкой.

Публичный репозиторий работает без токена. Для закрытого репозитория или
увеличения лимита GitHub можно сохранить fine-grained токен с доступом
`Contents: read-only`. Он хранится локально отдельно от Cloud.ru и не
передаётся целиком в браузер. При перенаправлении скачивания на codeload
заголовок авторизации удаляется.

Рабочие данные обновления лежат в `<данные>/updates/<идентификатор папки>`:
проверенные файлы, журнал установщика и резервные копии. Не заменяются
`YakumoData`, `YakumoDisk`, папки настроек и рабочего пространства,
портативный Python, `.venv`, `.git` и пользовательские файлы, которых нет
в списке обновляемого кода. Удаляются только файлы из ранее сохранённого
манифеста установленной версии, если их больше нет в новом коммите.

Номер версии определяется по коммиту и содержимому файлов: одинаковое
`0.1.0` в двух коммитах не скрывает обновление. После первой успешной
проверки или установки сохраняется локальный манифест. Локальные правки
обновляемых файлов сохраняются в резервной копии; посторонние модули
сохраняются на месте.

Если установка была прервана, при следующем запуске `Yakumo.bat`,
`Yakumo.pyw` или `python -m yakumo` проверяется журнал, и файлы
восстанавливаются до импорта ядра. Обновление Python и сторонних
библиотек этим модулем не выполняется. Если прежний порт уже занят,
выбирается свободный; при включённом открытии браузера откроется новый
адрес. Подробности ошибки остаются в журнале установщика и на странице
обновления.

## Модули

Модули подхватываются из `<программа>/modules` и `<данные>/modules`. Модуль —
файл `имя.py` или папка `имя/` с `__init__.py` и функцией `setup(ctx)`:

```python
NAME = "Привет"
VERSION = "1.0"

def setup(ctx):
    ctx.route("/api/hello", lambda request: {"hello": "мир"})
    ctx.status(lambda: {"ok": True})   # попадёт в /api/status
    ctx.on_stop(lambda: None)          # вызовется при выходе
```

Модуль может добавить свою страницу в веб-версию: `ctx.web("page.js", "page.css")`
подключает файлы из папки модуля, а скрипт вызывает
`Yakumo.addPage({ id, icon, title: { ru, en }, render })` (так сделан `modules/disk`).
Инструмент для чата: `ctx.chat_tool("имя", "что делает и какие аргументы", run)`;
с `change=True` Yakumo только предлагает его в плане, а выполняется он по кнопке.
`ctx.cloud` даёт модулю доступ к моделям Cloud.ru. `ctx.chat_context(hook)`
добавляет текст в подсказку чата, а `ctx.on_chat(hook(history, answer, chat_id, tools))`
вызывается после каждого ответа; `tools` — какие инструменты звались (так сделан
`modules/brain`). `ctx.services` — общие службы модулей: например, `services["disk"]`
отдаёт тексты документов Диска. `ctx.memory` — память Yakumo:
`remember(text, about=[...], files=[...])`, `recall(query)`, `say(text)`
(Yakumo напишет в чат первой). Обращайтесь к ней во время работы, а не в
`setup`: модуль «Мозг» может загрузиться позже вашего.

В `ctx` есть `paths`, `config` и `log`. Ошибка в модуле не ломает запуск,
она видна в `/api/modules`. Отключить модуль: `"disabled_modules": ["имя"]`
в настройках. Пример: `modules/hello.py`.

## Параметры

| Параметр | Что делает |
|---|---|
| `--info` | показать носители, выбранные пути и адрес, затем выйти |
| `--data-dir ПАПКА` | задать папку данных вручную (или переменная `YAKUMO_HOME`) |
| `--workspace ПАПКА` | папка, которая открывается по умолчанию |
| `--host АДРЕС` | адрес веб-версии (по умолчанию `127.0.0.1`) |
| `--port ПОРТ` | желаемый порт (по умолчанию 8765); если занят, берётся следующий свободный |
| `--lan` | открыть веб-версию для локальной сети |
| `--no-browser` | не открывать браузер |
| `--no-tray` | без значка в трее |

## Как выбирается носитель

1. `--data-dir` / `YAKUMO_HOME`, если заданы.
2. Портативный режим: если рядом с программой есть файл `portable` или папка
   `YakumoData`, либо программа запущена со съёмного диска, данные хранятся в
   `YakumoData` рядом с программой.
3. Иначе выбирается доступный для записи диск с наибольшим свободным местом
   (не менее 512 МБ), несистемные диски в приоритете: `D:\YakumoData`.
   На системном диске данные кладутся в `%LOCALAPPDATA%\Yakumo`.
4. Резервный вариант: папка пользователя или временная папка.

Внутри папки данных: `config/yakumo.json`, `logs/`, `cache/`, `temp/`, `workspace/`, `modules/`.

## Структура

```
yakumo/
  app.py            точка входа, аргументы командной строки
  core/storage.py   выбор носителя
  core/paths.py     рабочие пути
  core/network.py   адреса машины и поиск свободного порта
  core/config.py    настройки
  core/instance.py  один экземпляр
  core/modules.py   загрузка модулей
  tray.py           значок в трее
  web/server.py     веб-сервер (/api/status и статика)
  web/static/       страницы веб-версии
modules/            модули (пример: hello.py; disk/ — «Диск», brain/ — «Память»)
tools/build_portable.py  портативная сборка для Windows
```

## Русский язык

- `Yakumo.bat` написан только латиницей: cmd.exe читает .bat в кодировке консоли,
  и кириллица внутри ломает команды. Русские сообщения лежат в `launcher/*.txt`
  (UTF-8) и выводятся после `chcp 65001`.
- Python запускается в режиме UTF-8 (`-X utf8`), вывод в консоль не падает
  ни в какой кодировке.
- Все файлы читаются и пишутся в UTF-8; `yakumo.json`, сохранённый Блокнотом
  с BOM, тоже читается.
- Работают русские пути (`C:\Users\Иван\...`), русские имена модулей и адресов
  (`/api/привет`), русское имя компьютера; текстовые файлы веб-версии
  отдаются с `charset=utf-8`.
- Свои файлы сохраняйте в UTF-8.
